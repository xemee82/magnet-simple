# MagnetSimple 使用说明

MagnetSimple 是一款轻量原生 macOS 窗口管理工具，专为高效、极简的窗口分屏与整理打造。

> ⚠️ **操作系统说明**：本软件为 **macOS 原生专属应用**（适用于 macOS 13+ 的 Apple Silicon 与 Intel Mac），**不支持 Windows 或 Linux 操作系统**。若在 Mac 上外接了 Windows/PC 布局的键盘，软件已内置键位兼容。

---

## 1. 安装与使用指引

应用提供纯净绿色的单个 App 格式与 ZIP 压缩包：
* **解压与放置**：解压 `MagnetSimple.zip` 获得 **`MagnetSimple.app`**。强烈建议将其移动到系统的**「应用程序」文件夹（`/Applications`）**，以便开机自启动与权限配置长期稳定；
* **跨设备分享推荐**：如果分享给同事，推荐优先使用 Mac 的 **「隔空投送（AirDrop）」** 直接发送 `MagnetSimple.app`，通过 AirDrop 传输的应用通常可以直接双击打开，体验最顺畅。

---

## 2. 首次打开遇到安全拦截提示（Gatekeeper 放行）

由于本工具为轻量自编译应用，未向苹果年费官方商业证书公证，如果是通过**微信、网盘或邮件**下载的，首次打开可能会弹出：
*“‘MagnetSimple.app’ Not Opened / Apple could not verify...”* 或 *“无法验证开发者”*。

> **特别注意**：弹窗中请**不要**点击蓝色的 “Move to Bin（移到废纸篓）”，点击 **「Done（完成）」** 关掉即可。

### 快速放行方法（二选一）：

* **方法 A（系统设置点击放行，推荐）**：
  1. 关掉拦截弹窗后，打开 Mac **「系统设置」**（System Settings）；
  2. 点击左侧 **「隐私与安全性」**（Privacy & Security），向下滑动到「安全性」区域；
  3. 看到提示 *“MagnetSimple.app 已被阻止使用...”*，点击右侧的 **「仍要打开（Open Anyway）」** 按钮；
  4. 输入开机密码或触控 ID 确认即可打开。
  *（注：此操作仅需进行一次，系统会永久加入受信任白名单，之后双击直接秒开）*。

* **方法 B（终端一行命令彻底清除隔离标记）**：
  打开终端（Terminal），复制执行以下命令：
  ```bash
  xattr -cr /Applications/MagnetSimple.app
  ```
  回车后即可直接双击打开，不再有任何拦截提示。

## 3. 开启辅助功能权限（窗口控制必需）

macOS 安全机制要求窗口控制软件必须获得**辅助功能权限**：

1. 首次打开应用时，系统通常会自动弹出授权申请；
2. 若未弹出，请前往：
   **「系统设置」→「隐私与安全性」→「辅助功能」**（Accessibility）；
3. 在列表中找到 **MagnetSimple** 并勾选开启开关；
4. **无需重启应用**：软件内置自动检测，授权开启后 2 秒内快捷键即自动生效。

---

## 4. 如何设置开机自动运行

### 方法一：菜单栏一键开启（推荐）
1. 运行应用后，屏幕右上角顶部菜单栏会出现**马蹄形磁铁图标**；
2. 点击磁铁图标，在菜单中点击 **「开机自启动」**；
3. 选项前显示 **勾选状态（✓）** 即代表开启成功；
4. 若需关闭开机自启动，再次点击取消勾选即可。

### 方法二：在系统设置中核对
如需确认自启动状态：
1. 打开 Mac **「系统设置」** → **「通用」** → **「登录项与扩展」**；
2. 确认在「在登录时打开」列表中已包含 `MagnetSimple`，且在「允许在后台」中保持开启。

## 5. 核心快捷键指南

| 标准快捷键 | 兼容快捷键 (仅按 Control) | 功能说明 |
|:---|:---|:---|
| **⌃⌥←** | **⌃←** (`Control + 左箭头`) | **左侧循环吸附**：在「左一半 (1/2)」、「左三分之一 (1/3)」和「左三分之二 (2/3)」之间循环切换 |
| **⌃⌥→** | **⌃→** (`Control + 右箭头`) | **右侧循环吸附**：在「右一半 (1/2)」、「右三分之一 (1/3)」和「右三分之二 (2/3)」之间循环切换 |
| **⌃⌥↩** | **⌃↩** (`Control + 回车键`) | 将当前聚焦窗口在**最大化**与**还原**原本尺寸之间切换 |

> **Windows 键盘兼容**：如果给 Mac 外接了 PC/Windows 布局键盘（往往只有 Control 键而缺少 Option 键），在 Mac 上直接单按 **`Control + 方向键/回车`** 即可触发完全相同的分屏与全屏切换效果。

### 循环切换与特性说明
* **向左循环**：当窗口吸附到最左侧后，继续按快捷键 `⌃⌥←`（或 `⌃←`），窗口将在 **左三分之一 (1/3) → 左三分之二 (2/3) → 左一半 (1/2)** 之间循环轮转。
* **向右循环**：当窗口吸附到最右侧后，继续按快捷键 `⌃⌥→`（或 `⌃→`），窗口将在 **右三分之一 (1/3) → 右三分之二 (2/3) → 右一半 (1/2)** 之间循环轮转。
* **双向还原记忆**：使用最大化快捷键将窗口铺满全屏后，再次按下该快捷键，窗口会精确还原回最大化前的位置与大小。
* **独立窗口记忆**：每个 App 窗口独立记忆自身的状态，互不干扰。
* **多显示器自适应**：以当前鼠标或聚焦窗口所在屏幕为基准，自动扣除菜单栏与 Dock 栏高度。

## 6. 常见问题排查（FAQ）

**Q1：在「系统设置 → 辅助功能」中明明勾选了，为什么菜单栏仍提示「⚠️ 等待辅助功能授权」？**
* **完全退出后重新打开**：修改辅助功能权限后，macOS 要求必须重启进程才能刷新凭证。点击菜单栏「退出 MagnetSimple」后重新打开即可。
* **重置旧缓存条目**：若之前运行过旧版本，前往「系统设置」→「隐私与安全性」→「辅助功能」，选中 MagnetSimple 点击底部的 **`-`（减号）** 删除，然后重启应用重新授权一次。

**Q2：按快捷键后窗口没有反应？**
* 检查菜单栏磁铁图标中是否显示「⚠️ 等待辅助功能授权」，若是先完成授权；
* 检查当前聚焦的窗口是否是不可缩放的窗口（如系统小工具、计算器等固定尺寸窗口）。

**Q3：开机自启动在重启电脑后没有运行？**
* 请确认应用是否已经放入了 `/Applications`（应用程序）目录。若放在下载文件夹被清理移动，系统登录项会找不到原路径。
